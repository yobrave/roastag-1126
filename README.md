# Roast Your Own Agent

One line, at most 200 characters: the harshest, funniest roast of the AI agent its own team built. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
